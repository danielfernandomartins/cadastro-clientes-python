# 👥 Cadastro de Clientes em Python

Aplicação de terminal para cadastro e consulta de clientes, criada para praticar fundamentos de Python em um cenário simples de relacionamento e organização de dados.

## Contexto

O projeto usa um problema comum de negócio — **cadastro de clientes** — para demonstrar como informações podem ser estruturadas e manipuladas por software.

## Funcionalidades atuais

- Cadastro de clientes
- Armazenamento temporário em memória
- Listagem de registros
- Menu interativo

## Competências demonstradas

- Estruturação de dados com listas e dicionários
- Uso de funções
- Controle de fluxo
- Entrada e validação básica de informações
- Organização de regras simples de cadastro

## Tecnologias

**Python** • Terminal • GitHub

## Limitações atuais

Os dados são mantidos apenas durante a execução. O projeto ainda não possui persistência, autenticação ou API.

## Próximas evoluções

- Validação de dados
- Busca, edição e exclusão
- Persistência em PostgreSQL
- API REST com FastAPI
- Testes automatizados

## Visão para Operações de TI

Apesar de simples, o projeto trabalha com pontos recorrentes em suporte de sistemas: entrada de dados, validação, consulta de registros e comportamento esperado da aplicação.

### Situações de suporte que o projeto ajuda a entender

- Registro não encontrado
- Dado preenchido incorretamente
- Falta de persistência
- Necessidade de validação
- Diferença entre erro do usuário e limitação do sistema

## Como explicar em entrevista

> "Usei um cadastro simples para praticar o ciclo de entrada, armazenamento e consulta de dados. Em uma função de suporte, esse tipo de raciocínio é importante porque muitas ocorrências começam em cadastro incorreto, dado inválido ou comportamento esperado do sistema."

## Relação com minha experiência

Escolhi cadastro de clientes por ser um domínio que já conheço e usei esse conhecimento para aprender como o processo aparece dentro de um sistema.
